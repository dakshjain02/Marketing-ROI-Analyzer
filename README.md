# 📊 Marketing ROI Analyzer

An AI-powered Marketing ROI Analyzer built with Flask, Machine Learning, and Data Analytics to evaluate campaign performance, automate data preprocessing, predict ROI, and generate professional business reports.

---

## 🚀 Features

### 📂 Dataset Upload

* Upload marketing campaign datasets in CSV format
* User-friendly and responsive interface

### 🔍 Data Quality Analysis

* Missing Value Detection
* Duplicate Record Detection
* Outlier Detection using IQR Method
* Before vs After Data Quality Comparison

### 🧹 Automated Data Preprocessing

* Missing value handling
* Duplicate removal
* Outlier treatment
* Data cleaning pipeline

### 📈 Business Analytics

* Revenue Analysis
* Profit Calculation
* ROI Calculation
* Conversion Rate Analysis
* Cost Per Click (CPC) Analysis

### 🤖 Machine Learning Integration

* Multiple ML Models Evaluation
* Automatic Best Model Selection
* ROI Prediction
* Model Accuracy Comparison

### 💡 Business Intelligence

* Campaign Performance Insights
* Best Campaign Identification
* Revenue-Based Recommendations
* AI-Generated Business Suggestions

### 📄 PDF Report Generation

* Professional Report Export
* KPI Summary
* Data Quality Report
* Business Metrics Overview
